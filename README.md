# Opus (modified copy)

> **Modified copy.** This is a modified copy of Opus 1.6.1, maintained by Barely Soldered at https://github.com/Barely-Soldered/opus (tag v1.6.1-bs.1) for its own projects: rebuilt for meson alone, float-only, without SIMD, with the tree restructured as src/ and include/opus/. It is not the original software, which is at https://github.com/xiph/opus. The licence is unchanged; see COPYING.

Opus is a totally open, royalty-free, highly versatile audio codec. The original project's documentation is at https://opus-codec.org/.
